# gnustep-games
A collection of GNUstep Games to be used with AGNoStep Apps Manager.

## Goal

This module is useful with [agnostep-apps-manager](../../../agnostep-apps-manager).
It allows to retrieve the source of most of the known
GNUstep Games like Chess, NeXTGo... and then to build and install them into a GNUstep Desktop.

> [!NOTE]
> This is a work in progress, as we are replacing
> previous `AgnostepManager.app` with this new module method.
